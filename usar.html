Extrato Claro

Veja e organize seus extratos do Inter e da B3. Os dados ficam no seu computador, sem conta na nuvem.

Baixar para Windows

  1. Clique com o botão direito no ZIP e escolha “Extrair tudo”. Não abra o aplicativo de dentro do ZIP.
  2. Na pasta ExtratoClaro, abra ExtratoClaro.exe. O painel aparece no navegador.
  3. No painel, abra “Importar PDF”, escolha seu extrato ou fatura e importe. Use “Triar” para organizar os gastos sem categoria.

Seus dados são seus

Os extratos não saem do computador. Para encerrar, use “Fechar o aplicativo” na janela do Extrato Claro. Feche o app antes de copiar fin.db para fazer backup.

A conexão com Mercado Pago é opcional e não vem configurada. Esta versão não é uma conta bancária nem uma recomendação de investimento.

02

WINDOWS 10/11 · 64 BITS

Claude Autosend

Escreva uma tarefa e escolha quando enviá-la ao Claude Code. Você configura o agendamento no navegador.

Baixar para Windows

  1. Clique com o botão direito no ZIP e escolha “Extrair tudo”. Não abra o aplicativo de dentro do ZIP.
  2. Abra o arquivo Abrir-Claude-Autosend.vbs na pasta extraída. O Node já vem no pacote.
  3. No painel, escolha o horário, adicione uma sessão e escreva a tarefa. Confira a pasta do projeto antes de agendar.

Precisa do Claude Code

Você precisa instalar o Claude Code e conectar sua própria conta antes de enviar tarefas. O pacote não inclui uma assinatura nem acesso ao Claude.

Instalação oficial do Claude Code (nova aba)

O computador deve ficar ligado e acordado. As permissões normais continuam ativas; uma tarefa pode esperar sua aprovação. O modo “janela existente” precisa da área de trabalho desbloqueada e pode mudar o foco.

Antes de abrir um programa

Estes pacotes ainda não têm assinatura digital. O Windows pode mostrar um alerta. Só execute se reconhecer a origem; não desligue seu antivírus. Confira o nome e o hash do arquivo abaixo.
